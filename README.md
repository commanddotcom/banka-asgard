# Банка

Laravel + Tailwind + MySQL сайт для генерації QR-кодів поповнення банок
Monobank (НБУ "розрахунковий QR-код"), з адмінкою для керування банками,
рахунками та користувачами.

## Запуск (Docker)

```bash
docker compose up -d --build
```

Сайт буде доступний на http://localhost:8080. Міграції та сідер виконуються
автоматично при старті контейнера `app`.

## Архітектура

- **app** — веб-сервер (Laravel).
- **scheduler** — виконує `php artisan schedule:work`, який кожні 10 хвилин
  запускає автоматичну перевірку надходжень через Monobank API.
- **db** — MySQL.

Дані підключення до БД та ключі знаходяться у `.env` (не в git) — перед
продакшн-розгортанням обов'язково змінити паролі та `APP_KEY`.

## Модель даних

- **banks** (банки) — реквізити банки, токен Monobank API, прапорець
  автоматичного відстеження надходжень.
- **invoices** (рахунки) — рахунок на поповнення, прив'язаний до банки, зі
  статусом `unpaid`/`paid`.
